# DeskCare 吉祥物资源

用户于 2026-10-20 提供六张角色插画；采用内置 image_gen 工具生成保留角色的透明底副本，未使用额外 API Key、CLI 或本地模型。原始附件不覆盖。资源可用于本项目不表示已独立核实第三方知识产权，公开发行前应由项目方确认使用权。

未打卡/未授权时使用 skip 外观作为中性占位，但提示为“今天未记录状态”，不据此写入或推断任何健康记录。拖动及贴边态只是暂时覆盖显示，结束后回到当日主动选择的状态。

处理要求：background-extraction，仅把白色背景（左右贴边图还包括墙面）转成真正 alpha 透明，保留角色面部、表情、姿势、发丝、服饰、配饰、颜色和画风，不增加场景或文字；贴边图不补画原本被墙遮挡的身体，贴靠方向保持原图。

最终逐图提示词与附件/生成结果映射保存在 `design/mascot-prompts.json`。运行期仅加载随包 PNG，不上传图片、状态、活动或用户数据，不使用 Live2D。
