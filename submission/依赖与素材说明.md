# 依赖与素材说明

本轮构建环境：Windows 11 x64、Python 3.12.7、PySide6 6.12.0、PyInstaller 6.22.3。支持的源码 Python 版本以 pyproject.toml 为准，为 3.11/3.12。SQLite 使用 Python 标准库。

- Python：运行时许可文本随包保留。来源 https://www.python.org/ 。
