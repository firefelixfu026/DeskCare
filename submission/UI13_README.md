# DeskCare UI13 Windows 体验版

解压整个文件夹后运行 DeskCare-UI13.exe，不要单独移动 exe 或删除 _internal。

快速演示：运行 START-DEMO.cmd，进入虚构任务与使用统计演示。此入口使用演示数据库，不代表电脑真实使用记录。

普通使用：运行 DeskCare-UI13.exe。首次使用按需开启各项授权；不开 AI 也能管理任务、提醒与生成本地小结。若旧版正在运行，请先从系统托盘正常退出旧版再启动，以免单实例机制带回旧界面。

建议体验：今日任务与分页／多选 → 使用统计的每日、每周与小时视图 → 设置里的自定提醒间隔与“试一下提醒” → 个人状态记录 → 右上角检验单阅读。examples 里的血常规 PDF 和图片完全虚构，仅用于练习核对。

AI 需用户自己的服务配置及对应单独授权。助手可理解“把提醒改成一个小时”，但设置修改需要再确认。请勿把 API Key 粘贴到聊天或公开材料中。检验单原件不自动上传；辅助说明不诊断、不治疗，不替代就医。

本包为未签名的 Windows 体验版，不要为运行它全局关闭安全防护。下载来源与校验值以 GitHub 发布页为准。
