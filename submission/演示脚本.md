# DeskCare 两分钟演示

演示前先退出旧实例，再双击 Demo.cmd。明确告诉评委：窗口中是软件预置的虚构数据，用来说明流程，不是用户研究或真实模型结果。

前二十秒：说明目标用户是 Windows 学生和办公人群。打开今日任务，添加一个任务，切换状态；任务由用户确认，程序不会看应用就猜测做完了什么。

接下来二十秒：导入 `参赛验收清单.md`，展示草稿可以编辑和取消，点击确认才保存。这一段先使用离线解析；真实 AI 未验证时不展示伪造的推理过程。

接下来二十秒：打开使用统计，展示近七天柱状图、类别和应用排行。说明仅在授权后记录有限的日汇总，不读窗口标题、输入内容或网页地址。

接下来二十秒：说明会议、专注和任务期限会影响柔性提醒；提醒可推迟和跳过。用预置反馈展示流程，不临时改系统时间或把模拟提醒说成真实活动检测。

最后四十秒：展示日报、桌面伙伴以及两种样式的右键切换。状态表情只跟随用户主动保存的选项。最后指出暂停和退出入口，说明近期先验证兼容性、真实模型和普通用户体验；价格与付费意愿仍是商业假设。

录屏时只录演示窗口，不录私人聊天、任务、API Key 或真实状态数据。如伙伴贴边不稳定，演示使用面板模式，不现场扩大功能或改代码。
