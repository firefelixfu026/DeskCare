# DeskCare 提交与使用说明

版本：UI6，2026年10月20日。该版本停止扩展功能，优先保留可运行闭环。

## 普通体验

1. 解压 Windows 便携包，保留完整 `DeskCare-UI6` 文件夹，不要只复制 EXE。
2. 如果已经打开旧版，请先从系统托盘选择“退出”。再双击 `DeskCare-UI6.exe`，侧栏底部应显示 UI6。
3. 首次正常启动不采集电脑使用记录。直接点“添加任务”即可体验，不需要联网或设置 AI。
4. 想看完整虚构示例时，退出正常实例，再双击同文件夹的 `Demo.cmd`。窗口和报告会标记演示数据，使用独立演示库。
5. 关闭主窗口通常会留在托盘；完全停止请从托盘选择“退出”。没有系统托盘时保留可见退出方式。

便携版未签名。如果被系统拦截，请先核对来源和校验值，不要关闭杀毒软件或绕过安全提示；可以改为在可信开发环境从源码运行。

## 源码运行

使用 Python 3.11 或 3.12，在解压的源码目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m deskcare
.\.venv\Scripts\python.exe -m pytest -q
```

只需要运行时，可用虚拟环境中的 Python 执行 `-m pip install .` 安装项目运行依赖。构建入口为 `scripts/build_windows.ps1`。首次授权、实际数据均与演示实例区分；升级前自行备份 `%LOCALAPPDATA%\DeskCare`，不要公开该目录。

## AI 与数据

没有 AI 服务也能管理任务、授权统计、接收提醒和查看模板报告。本地模型服务未运行，当前用户目录未配置模型且未授权 AI；未完成真实推理验收。不要把演示数据说成真实 AI 输出。

云端功能只整理用户主动选择、预览并逐次确认的任务文字。需要自行配置服务和密钥，可能由服务商计费；本次没有购买服务或创建新付费接口。密钥不得写进源码、截图或聊天。

电脑使用时间是估计，不代表真实工作时长；任务完成和状态由用户确认，不提供医学诊断。应用不自动上传使用统计或状态打卡。
