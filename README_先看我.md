# DeskCare — Codex 开发交接包

**项目名称**：DeskCare｜**更新**：2026-10-20｜**状态**：当前运行版为 UI11。本轮按用户顺序升级提醒：反馈提出间隔复核建议，不自动加 5 分钟；可主动让 AI 分析选定任务、当前情境和可选本次感受，单独授权并逐次预览确认，间隔变更还需确认。启动 `dist/DeskCare-UI11/DeskCare-UI11.exe` 前先从托盘退出旧版，详见 `docs/UI11_提醒安排与AI建议.md`。UI10 本机不适记录闭环继续保留，历史健康内容不进入 AI；医院检验单辅助阅读下一阶段才做。旧版和参赛快照保留，验证边界见 `PROGRESS.md`。

> 产品一句话：一款面向 Windows 学生与知识工作者的**本地优先、用户可控**数字健康桌面助手，将应用使用统计、今日任务、柔性休息建议、自主状态打卡和可追溯日报/周报串联成一个闭环。

## 为什么不是“三个工具拼接”？

核心竞争假设不是番茄钟、待办、统计或 AI 文案本身，而是**跨模块决策**：用户的计划提供时间约束；电脑只提供有限的活动信号；用户本人确认任务和感受；策略引擎据此选择更适合提示的时机，并解释理由。未经测试，不能宣称比现有工具更健康、更高效。

## 从这套文档开始

1. 创建或打开 **DeskCare 项目仓库**，把以上文件原样放入根目录。
2. 若已经让 Codex 实现过 DeskCare v1，**请备份旧代码，并让 Codex 先盘点现有仓库**；不要重建项目或覆盖可用代码。旧版的 PySide6 托盘、ActivityProvider、SQLite、休息策略可以复用。
3. 在 Codex 中打开仓库，粘贴 `CODEX_启动与续接指令.md` 内的 **首次启动指令**。
4. **一次只做一个里程碑**，先 M0。Codex 每次报告变更、真实运行的测试、限制，等你确认再继续。
5. 优先在 **Windows 10/11 + Python 3.11/3.12** 上开发和实际验证；非 Windows 环境只可用 FakeProvider 单测，不得宣称真实 Windows 检测已通过。

## 比赛优先级

- **先验证闭环**：导入任务 → 用户确认 → 收集有限活动数据 → 触发/推迟柔性休息 → 主动状态打卡 → 生成**不杜撰**的数据报告。
- **首轮交付**：可执行程序、可信演示、样例数据、源代码、测试结果、简短项目说明。
- **禁止抢跑**：摄像头、截图、键盘内容、窗口标题、网页 URL、自动读取任何文档、强制应用锁、跨设备同步、临床诊断都不在 MVP。
- AI 增强是可选运行依赖，**没有配置 AI 服务时仍必须完整可用**。但如果以“AI 产品”参赛，演示时至少应有一条**实际运行的模型推理链路**（如用户选择清单后经本地模型解析，并确认草稿），不能把规则引擎冒充已训练 AI。
- 联网 AI 默认关闭；开关本身不会联网。任务清单只在逐次确认后发送；UI11 的提醒分析新增独立许可，只发送本次预览确认的情境最小快照和选定任务，可选感受由用户本次选择，不读取状态／不适历史或使用轨迹。服务密钥由 Windows 凭据管理器保存，不包含在预览正文中。
