# DeskCare UI3 迭代报告

## 本轮实现

- 保留 UI2 的浅色控件、连续图表动画、七天状态回顾和语音移除；新增设置中的“简洁面板 / 吉祥物”样式切换。样式本地持久化，与显示、统计和状态授权分离，不会自动打开任何授权。
- 使用用户提供的六张插画：图 3 对应“无明显不适”，图 2 对应“有点不适”，图 4 对应“不想记录”；图 1 为拖动；图 5/6 为左右贴边。没有按任务、使用时长或提醒推断身体状态。
- 三种日常表情只使用今天主动保存的状态。删除今天记录、撤回授权或跨天无新记录后，清除旧状态显示；未记录使用 skip 图片作为占位，提示“今天未记录状态”，不生成打卡。
- 吉祥物单击打开原有任务/情境面板，可添加、勾选和返回；右键可打开主窗口、切回面板或隐藏。拖动超过系统阈值才换专用图，松开恢复；贴边使用对应探头图；隐藏中断拖动时清理临时状态。
- 透明画布和按轮廓的命中区域；布局忽略透明边缘微弱杂点，避免正方形原图空白让角色缩成小图。原图未覆盖，没有用白色矩形当透明素材。
- 情境选择同步提醒服务，但不触发统计授权。清空应用数据后回到默认面板样式，不重新写回已删除的偏好。

## 素材处理与边界

使用 imagegen 技能与内置 `image_gen` 工具，为六张用户供图制作透明底副本；提示要求仅移除背景/贴边墙面，保留角色、姿势和画风，不补画被墙遮挡的身体。没有使用额外 API Key、CLI 或本地语音/图像模型。最终 PNG 位于 `assets/mascot/`，逐图提示词、原附件文件名和生成结果对应见 `design/mascot-prompts.json`；这是设计期处理，不是应用运行时上传数据。

用户资料、状态与活动记录不发送给图像模型。源素材使用权未作独立核实，公开发行前需项目方确认。此版本是图片式吉祥物，不是 Live2D。

## 自动化与构建证据

- 最终全量：`QT_QPA_PLATFORM=offscreen`，`python -m pytest -o addopts= -q -rs -p no:cacheprovider --basetemp .pytest-ui3-final`：**133 passed, 1 skipped，27.82 秒，退出码 0**。唯一跳过项仍为沙箱受限的 localhost AI socket 探测。
- 150% Qt 缩放：界面、任务、报告、伙伴与 UI2/UI3 回归 **44 passed，11.36 秒**。最初固定坐标的拖动测试在缩放后实际拖到了屏幕边缘，正确触发贴边；已将非贴边拖动测试改为相对可用屏幕定位，保留独立左右贴边断言。
- 新增十二项 UI3 用例（含参数化）：偏好持久化且不自动开授权/显示、三种自报映射、无授权不读历史、昨天记录不沿用、点击任务面板、专用拖动态、左右贴边、六张图真实 alpha/轮廓/尺寸、新日期清除旧表情、隐藏中断拖动。
- `compileall`、`pip check`、`git diff --check` 通过。1040×680 和 1240×820 下各生成十六张离屏预览，包括六种角色姿态与任务面板；仅使用临时数据库、FakeProvider 和虚构记录。
- Windows 11 / Python 3.12.7 / PyInstaller 6.22.3 构建 `dist/DeskCare-UI3/DeskCare-UI3.exe`；九个应用/领域/UI 模块的包内代码指纹与最终源码一致，六张包内 PNG 与源码逐字节一致。未嵌入 Vosk、deskcare.voice 或 QtMultimedia。
- 可执行文件未签名。便携包大小、SHA-256 与最终归档核验见 `RELEASE_MANIFEST.md`。旧 UI1/UI2/M18 包未覆盖。

## Windows 实机走查（用户授权后）

采用 computer-use 技能和 `@oai/sky`，只操作明确选中的 `DeskCare-UI3.exe`，以 `--demo-scenario` 启动，并将 `LOCALAPPDATA` 指向项目 `build/ui3-live-*` 独立目录。没有操作真实监测、AI/Windows 权限或用户个人记录。

最初未取得可操作的新窗口，一度怀疑旧实例影响；持续保留启动会话后，确认新 UI3 窗口与旧 UI1 分属不同可执行路径，可独立测试。工具第一次应用控制授权超时，重新授权/观察后恢复；不将这些现象记为已证实的应用单实例缺陷。用户后来也允许退出旧版，但实际不必退出，旧 UI1 保持原状。
