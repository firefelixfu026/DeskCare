# M3 Windows 人工验收清单

在目标 Windows 设备使用项目虚拟环境执行。每项记录“通过/失败/备注”，失败时保留截图和时间点，不要把真实个人活动数据提交到仓库。

## 启动与授权

- [ ] `python -m deskcare` 可以启动，首次启动活动监测保持关闭。
- [ ] 窗口标题为 DeskCare，四个页面均可切换。
- [ ] “设置与隐私”中开启/关闭监测后，页头和“今日”状态一致。
- [ ] 暂停监测后，provider 不再被读取，提醒卡片消失；恢复后重新建立样本基线。

## 提醒交互

- [ ] “当前情境”可切换普通工作、专注、会议、阅读、安静时段。
- [ ] 提醒出现时是页面内联卡片，不弹模态框、不抢焦点、不改变当前输入窗口。
- [ ] 四个反馈按钮均可点击，点击后卡片消失且不会立即重复提示。
- [ ] 会议/安静情境下不显示提醒；未确认任务不会被当成日程依据。
- [ ] 完成任务只能通过今日页下拉框主动修改，提醒策略不会自动改任务状态。

## 托盘与长期运行

- [ ] 关闭窗口后可通过托盘“打开 DeskCare”恢复窗口。
- [ ] 托盘“暂停/恢复监测”和窗口内状态一致。
- [ ] 托盘退出后进程结束，SQLite 文件可再次打开且不损坏。
- [ ] 高 DPI（100%/150%）下卡片、按钮和表格无明显裁切。

## 隐私与文案

- [ ] 关闭监测时使用统计不显示虚假 0 分钟。
- [ ] 页面和提醒没有医学诊断、疲劳判定或“保证改善”类表述。
- [ ] 检查 SQLite 仅包含聚合数据、已确认任务和提醒反馈，不包含窗口标题、URL、键盘内容、截图或文件全文。
