# M4 验收记录

## 范围

M4 实现 BodyLog 自主状态记录与忠于数据的本地日报/周报。状态打卡是独立敏感能力，默认关闭、单独授权、可删除；报告只从本地结构化聚合事实生成，不把电脑活动或自报舒适度解释为医学结论。

## 已实现

- SQLite v4 `wellness_entries` 增量迁移；每个本地日期最多保存一条用户主动选择的粗粒度舒适度。
- BodyLog 独立授权 `wellness_checkin`，首次默认关闭；未授权时不能写入状态记录。
- 支持“无明显不适 / 有些不适 / 不想记录”三个保守选项，不提供自由文本健康诊断入口。
- 今日状态页面支持保存、更新和删除当天自报；设置页支持清除全部 BodyLog 记录，清除不偷偷改变授权。
- `ReportFactsBuilder` 聚合 `usage_daily`、用户确认任务、`reminder_events` 和可选 `wellness_entries`。
- 活动覆盖分钟同时计算活跃、空闲和未知观测区间，避免用活跃分钟冒充全天覆盖；无授权/无记录时显示缺失而不是虚假的 0。
- `TemplateNarrator` 输出本地 Markdown 日报/周报，列出时间范围、数据覆盖、来源和缺失；周报少于 3 个有效活动日不做趋势判断。
- 报告支持界面查看和用户主动导出 Markdown；未接入云端模型，模板生成不冒充 AI 医学报告。

## 自动化证据

在项目虚拟环境中执行：

```powershell
python -m compileall -q deskcare tests
python -m pytest -q
python -m pip check
```

M4 回归覆盖数据库 v4 迁移、独立授权、禁用写入、保存/更新/删除/清除、FactSheet 数字核对、提醒反馈汇总、缺少健康授权、周报样本不足、报告禁用医学表述和 M0-M3 回归。当前工作区阶段回归为 **36 passed**。

无头 Qt 装配冒烟验证四页窗口、BodyLog 默认关闭、开启授权后保存自报以及报告刷新。真实 Windows 托盘、DPI 和文件导出对话框仍需按人工清单在目标机验证。

## 隐私与伦理检查

- BodyLog 与活动监测分别授权；关闭 BodyLog 时不会写入自报。
- 数据库存储粗粒度用户选择，不存病历、诊断、自由文本或推断值。
- 报告明确写出“用户主动填写”“估计值”“数据缺失”和“本地模板”，不输出疲劳、视力、情绪或疾病判断。
- 报告不从前台类别推断任务完成；完成数只来自用户主动修改的任务状态。
- 导出只有在用户选择保存路径后发生，导出的内容不含窗口标题、URL、键盘内容或原始活动样本。
