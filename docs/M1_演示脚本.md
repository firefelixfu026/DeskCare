# DeskCare｜M1 60–90 秒演示脚本

## 0–10 秒：定位

“DeskCare 是一个 Windows 本地优先、用户可控的电脑使用习惯辅助工具。它只提供有限活动估计，不是监控器、生产力评分器或医疗诊断器。”

启动真实模式：

```powershell
python -m deskcare
```

如果现场不希望依赖真实前台应用，可使用明确标记模拟数据的演示模式：

```powershell
python -m deskcare --demo
```

## 10–25 秒：默认授权

进入“设置与隐私”，指出活动统计默认关闭。此时“使用统计”显示未开启/暂无数据，而不是虚假的 0 分钟。

说明：没有用户明确开启时，provider 不读取 Windows 活动。

## 25–45 秒：开启并查看估计

手动开启“电脑活动统计：空闲秒数与粗粒度类别”，等待至少两个采样周期，进入“使用统计”。

展示：

- 今日活跃电脑操作估计；
- 空闲与未知时段；
- `CODE / BROWSER / OFFICE / OTHER / UNKNOWN` 等粗粒度类别；
- 当前连续活跃会话估计。

强调：类别不等于任务完成，也不保存窗口标题、网页 URL、文件名或完整进程路径。

## 45–60 秒：暂停与异常边界

点击“暂停监测”，展示状态变化；暂停期间不采样，恢复后从新的基线开始。

说明：超过 60 秒的采样间隔不会被算成持续工作，因此锁屏/睡眠不会自动补成活动时间；统计页会显示相应采样说明。

## 60–75 秒：本地控制

关闭窗口，展示托盘中的打开、暂停/恢复和退出。进入设置，点击“清除已保存的活动统计”，展示二次确认；确认后统计立即清空，授权状态不被偷偷改变。

## 75–90 秒：路线与边界

“M1 只完成受控活动采样和类别统计。后续 M2 才会做用户主动选择的任务清单导入；提醒、健康自报、事实报告和可选 AI 仍需独立授权，不能把当前活动估计解释成疲劳、视力或健康结论。”

## 不应声称

- “检测到了疲劳/眼疲劳/健康风险”；
- “自动判断用户是否完成任务”；
- “使用某个应用就证明在学习或工作”；
- “模拟数据来自真实用户”；
- “锁屏或无输入就等于完成了休息”。
