# M2 Windows 人工验收清单

项目目录：`E:\FelixFu\document\ZJU\2026AW\浙客松`

## 1. 启动与环境

```powershell
Set-Location 'E:\FelixFu\document\ZJU\2026AW\浙客松'
& .\.venv\Scripts\python.exe -m deskcare --demo
```

- [ ] 主窗口打开，左侧显示“今日”“使用统计”“状态与报告”“设置与隐私”。
- [ ] “今日”页显示“添加任务”和“导入清单”。
- [ ] `--demo` 只提供活动演示数据；任务文件仍须用户主动选择。

## 2. Markdown 导入

选择 `examples\今日清单.md`：

- [ ] 预览窗口出现候选任务，且提示“确认后才会写入”。
- [ ] `16:00` 显示需要人工核对日期/时间的提示。
- [ ] 文件中的 `[x]` 任务不会自动显示为“已完成”。
- [ ] 修改标题或预计分钟后，预览内容同步更新。
- [ ] 点击“确认导入”后，任务出现在“今日”列表。

## 3. CSV 导入

选择 `examples\tasks.csv`：

- [ ] `title`、`due_at`、`estimated_minutes` 正确显示。
- [ ] 截止时间和预计分钟能在预览表中编辑。
- [ ] 关闭预览或点击“取消”后，今日列表任务数量不变。
- [ ] 确认后任务状态默认为“待处理”。

## 4. 手工管理

- [ ] “添加任务”可以创建无截止时间任务。
- [ ] 选中任务后可以编辑标题、截止时间、预计分钟。
- [ ] 状态可以切换为“进行中”和“已完成”。
- [ ] 已完成任务可以重新改回“待处理”。
- [ ] 删除任务前出现二次确认，选择“否”时任务保留。

## 5. 边界和隐私

准备临时测试文件，不要选择真实隐私文件：

- [ ] 空文件：显示错误，不能确认。
- [ ] 非 UTF-8 文件：显示编码错误，未导入。
- [ ] CSV 缺少 `title` 或包含未知列：显示列错误，不能确认。
- [ ] 损坏 CSV：显示格式错误，不能确认。
- [ ] 重复标题：确认按钮不可用；编辑或移除重复项后才可确认。
- [ ] 取消导入不会新增任务。
- [ ] 关闭“开启电脑活动统计”后，任务添加、导入和状态修改仍可用。
- [ ] 应用不会扫描未选择的目录或文件；数据库只保存确认后的任务和源文件名。

关闭应用后执行：

```powershell

& .\.venv\Scripts\python.exe -m pytest -q
& .\.venv\Scripts\python.exe -m pip check
```
