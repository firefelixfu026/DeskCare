## DeskCare UI14 Windows 体验版

下载 `DeskCare-UI14-Windows-x64.zip`，解压完整目录后运行 `DeskCare-UI14.exe`；也可运行 `START-DEMO.cmd` 查看虚构数据演示。先从托盘退出旧版，保留完整 `_internal` 目录。本包未签名，不建议全局关闭安全防护。

本次只优化已有任务管理：

- 完成的任务移到“已完成任务”，按完成时间排序并按日期筛选，支持重新打开与批量管理。
- 长期任务支持开始／结束日期，CTF 比赛等跨多天事项只保留一条任务，不每天复制，不自动完成。
- 明确的完整日期范围可从清单导入；日期、预计用时和独立截止时间分开处理。
- 保留既有统计、提醒、状态记录、助手与检验单阅读，不扩大健康数据授权。
