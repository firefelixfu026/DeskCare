# M5 演示脚本

## 运行源代码版本

```powershell
python -m deskcare --demo
```

说明 `--demo` 使用显式标注的 FakeProvider；不联网、不读取真实活动。

## 交付能力演示

1. 打开一个 DeskCare 实例，再执行一次 `python -m deskcare --demo`；第二次不会创建第二个窗口/采样会话，已有窗口收到显示请求。
2. 关闭窗口；有托盘时从托盘打开，确认退出动作仍可结束进程；无托盘时可见窗口仍可关闭退出。
3. 在设置页点击“清除 DeskCare 全部本地数据”，先选择“否”确认不删除，再选择“是”确认活动、任务、提醒、BodyLog 和授权状态都被清除。
4. 执行 `python .\scripts\run_baseline.py`，说明输出是虚构情境的行为对照，不是疗效、生产力或健康研究。

## Windows onedir 构建

1. 安装 `requirements-dev.txt`。
2. 执行 `powershell -ExecutionPolicy Bypass -File .\scripts\build_windows.ps1`。
3. 从 `dist\DeskCare\DeskCare.exe` 启动，不依赖 IDE；将整个目录作为交付物。
4. 退出后删除 `dist\DeskCare` 即可移除程序；用户本地数据目录需要另行确认后清除。
