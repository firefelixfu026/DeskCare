# M6 Windows 人工验收清单

## 默认关闭与规则链路

- [ ] 新用户启动后，本地 AI 默认关闭，活动监测和 BodyLog 仍分别保持各自默认状态。
- [ ] 本地 AI 关闭时导入清单仍可正常生成规则草稿；不会尝试访问 `127.0.0.1:11434`。
- [ ] 取消预览不写入任务；只有点击“确认导入”才写入。

## 本地模型链路

- [ ] 准备本机 Ollama-compatible 服务后，开启本地 AI授权；设置页说明为“仅回环地址、不上传云端”。
- [ ] 本地 AI 关闭时“检测本机模型”不可用；开启后点击检测，等待期间主窗口仍可操作，且说明不会发送任务、报告或 BodyLog。
- [ ] 服务在线但没有模型时明确显示空模型状态；存在模型时列出有限预览，并说明当前配置模型是否在列表中。
- [ ] 在设置页把模型名改为本机实际存在的模型并保存；保存不联网，重启 DeskCare 后配置仍保留。
- [ ] 输入 `https://example.com/api/chat` 后保存应被拒绝，原有合法配置不被覆盖。
- [ ] 选择一个包含明确 `YYYY-MM-DD` 日期的任务文件，点击“本地 AI 提议”；按钮显示处理中，但对话框仍能重绘和操作，规则草稿在模型结果返回前不消失。
- [ ] 模型处理期间取消导入；稍后到达的模型结果不得重新打开对话框、写入任务或覆盖下一次导入。
- [ ] 选择只写“明天/下午”的任务文件，确认日期不会被模型静默写成用户事实，而是显示待确认或留空。
- [ ] 修改标题、截止时间和预计分钟后确认导入，今日任务显示人工最终值。
- [ ] 停止本地模型服务，重复导入，确认出现非阻塞回退提示且规则任务仍可确认。
- [ ] 点击“本地 AI 改写”后拖动/切换页面，确认主窗口仍可响应；模型不可用时最终回到模板报告。
- [ ] 尝试配置外部 URL（如果通过代码或环境扩展），确认客户端拒绝非回环地址。

## 隐私与交付包

- [ ] 数据库没有任务原文、模型原始响应或绝对源文件路径。
- [ ] 执行“清除 DeskCare 全部本地数据”后，本地 AI 授权和 endpoint/model 配置均恢复默认/关闭。
- [ ] 断网状态下规则导入、提醒、BodyLog 和模板报告仍可用。
- [ ] onedir 包必须复制整个 `dist\DeskCare` 文件夹；如果只复制 exe，可能出现 `QtCore.dll 找不到指定的程序`。onefile 包可单独复制。
- [ ] 如果电脑安装了多个 Python/Qt，必须使用 `scripts\build_windows.ps1` 构建；脚本会隔离 PATH。不要从带有其它 Python 路径的自定义命令直接调用 PyInstaller。
- [ ] Clash 开启时重复执行本地模型链路；确认只访问回环 endpoint，代理开关不改变本地直连结果，也没有外部 URL 请求。
- [ ] M6 测试不将假的本地传输结果描述成真实模型质量或健康/效率效果。

## 提醒反馈个性化

- [ ] 新用户和演示模式下个性化默认关闭；演示模式的开关不可启用，并明确说明模拟反馈不参与学习。
- [ ] 真实模式下单独开启个性化；样本不足 10 条时显示实际进度并保持 40 分钟默认候选窗，不出现“已学会习惯”等表述。
- [ ] 累积至少 10 条反馈，但某一情境少于 5 条时，该情境仍保持默认并显示情境样本不足。
- [ ] 某一情境至少 5 条且“时机不合适”达到 40% 后，只将该情境候选窗延后 5 分钟；切换其他情境不复用该调整。
- [ ] 调整生效后暂停监测、会议/静默情境、观察缺失、临近已确认截止时间和冷却期仍优先，不产生强制提醒。
- [ ] 点击“恢复默认提醒参数”后立即关闭个性化并恢复默认；此前反馈仍保留。执行“清除全部本地数据”后反馈和授权均被删除。
