# DeskCare UI3：双模式桌面伙伴

## 打开

先从托盘退出旧 DeskCare，再运行 `DeskCare-UI3/DeskCare-UI3.exe`。侧栏底部显示 `DeskCare · UI3`。便携 ZIP 必须完整解压到新文件夹，EXE 与 `_internal` 不要拆开或混用旧版。UI2 的浅色弹窗、连续统计动画、状态回顾和无语音伙伴均保留。

## 选择喜欢的样式

进入“设置与隐私 → 常用设置”：

- “显示桌面伙伴”决定它是否出现，仍默认关闭。
- “伙伴样式”可以选择“简洁面板”或“吉祥物”。切换样式不会自动打开伙伴、监测或状态打卡；样式会在下次启动时保留。

简洁面板就是此前的任务/情境悬浮窗。吉祥物使用你提供的角色图透明底副本，不是 Live2D，也不需要额外安装模型。

## 吉祥物怎么用

- **单击**：打开任务/情境面板；可以快速添加、勾选任务，点击“返回”回到吉祥物。
- **拖动**：角色切换为被提起的专用图片；松手后恢复今天的表情。
- **靠左/右边缘松手**：使用对应的探头图片贴边显示；单击可展开。
- **右键**：查看任务、打开主窗口、切回简洁面板或隐藏。

## 三种表情

表情只跟随“状态打卡”里今天主动保存的选择：

| 用户选择 | 使用的角色图 |
| --- | --- |
| 无明显不适 | 图 3：开心伸手 |
| 有点不适 | 图 2：手扶额头 |
| 不想记录 | 图 4：垂手表情 |

没有单独开启状态打卡、今天尚未保存、删除今天记录或跨天后没有新记录时，不推断你的身体状态，也不自动生成打卡；使用“不想记录”图片作占位，悬停提示为“今天未记录状态”。关闭授权后不继续显示之前的状态表情。

吉祥物会把今天主动填写的状态显示在桌面上；不想展示时可切回简洁面板或隐藏伙伴。拖动和贴边图片只临时覆盖表情，不改变记录。所有状态与角色切换都在本机处理，不发送给 AI。

## 本轮边界

离屏自动化和虚构数据预览不能替代完整 Windows 验收。用户授权后，本机独立演示实例已验证启动、样式切换、三种打卡表情、任务弹窗添加、伙伴勾选同步与返回；真实贴边、跨屏拖动、托盘退出和长时间使用仍待确认，详见迭代报告。角色透明副本是设计期使用内置 image_gen 工具处理的资源，不是应用运行时联网功能；公开发布前仍应确认素材使用权。程序未签名。
