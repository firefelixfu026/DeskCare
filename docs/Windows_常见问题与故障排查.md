# DeskCare Windows 常见问题与故障排查

这份说明面向普通使用者。先记住：电脑使用统计第一次默认关闭；任务管理和本地模板报告不要求开启统计，也不要求配置 AI。UI2 已移除内置语音输入，直接输入任务即可。

## 程序打不开或提示 QtCore/DLL 错误

1. 如果使用便携版，确认已经把 ZIP **完整解压**，再运行里面的 `DeskCare-UI2.exe`；不要只把 exe 单独复制出来。旧版程序请按其随包说明运行。
2. 确认没有把一个版本的 exe 和另一个版本的 `_internal` 文件夹混在一起。最简单的恢复方式是将官方 ZIP 解压到一个新的空文件夹，再从新文件夹启动；不要覆盖或拼接旧目录中的文件。
3. 如需确认下载文件完整，在 PowerShell 中对 ZIP 运行：

   ```powershell
   Get-FileHash -Algorithm SHA256 .\DeskCare-UI2-windows-x64-portable.zip
   ```

   与项目的 `release/DeskCare-UI2-SHA256.txt` 对照。校验不一致时请重新获取压缩包，不要尝试替换 DLL。
4. 若仍打不开，记录 Windows 版本、使用的 ZIP 类型以及错误窗口中的错误文字。不要把 API Key、私人任务或健康记录发给他人。

DeskCare 当前发布包是未签名便携程序，不是安装器；Windows 可能显示 SmartScreen 提示。只有在确认压缩包来源并核对校验值后，再自行决定是否运行。不要为了启动程序而关闭系统安全防护。

## 看不到电脑使用时间

- 进入“设置与隐私”，确认是否由你主动打开了“电脑使用统计”。首次使用默认关闭；不开启时显示“未开启”是正常行为，不代表 0 分钟。
- 刚开启后需要一段时间积累样本；暂停期间不采样。恢复后会从新样本开始，不补算暂停或电脑休眠时间。
- 如果统计服务暂时不可用，今日页会提示这次没有记录或当前无法判断。任务管理仍可继续使用。
- “应用名称统计”是单独授权项；不开启时只显示类别汇总，不会保存具体应用名。

## 为什么没有“按住说话”

UI2 已按用户反馈移除内置录音、语音转文字和语音模型配置；悬浮伙伴只保留添加/勾选任务、切换情境及打开主窗口。升级不会删除已有任务或用户自行下载的模型文件，只移除已无用途的模型路径设置。若仍看到旧按钮，请从托盘退出旧版后再打开 UI2。

## 本机 AI 没有连接，或联网 AI 请求失败

- AI 都是可选功能；AI 不可用时，规则导入和本地模板报告仍可用，不影响核心任务流程。
- “检测本机模型”只检查本机回环地址的服务与模型列表，不会发送任务或报告。没有运行兼容服务或没有下载模型时，显示不可用是预期结果。
- 联网 AI 只有在设置中单独开启并确认本次发送内容后才会请求服务商。网络失败或超时不会替换原有规则草稿；检查网络、服务地址和凭据状态后，可以取消并继续用规则草稿。
- 不要把 API Key 粘贴进问题反馈、日志、截图或任务内容。关闭联网 AI 时若系统提示凭据删除失败，请按界面提示到 Windows“凭据管理器”检查 DeskCare 凭据。

## 任务或日报保存失败

- 添加任务失败时，先检查标题是否为空、过长或与现有草稿重复；导入清单在确认前不会写入，取消预览不会丢失已有任务。
- 报告导出失败时，重新选择一个你有写入权限的文件夹和文件名；导出失败不会清除本机数据库中的记录。
- 如果问题反复出现，先退出 DeskCare，再复制需要保留的 Markdown 报告到安全位置。不要手工编辑或删除 SQLite 数据库文件。

## 数据在哪，如何清除

- 正式用户数据：`%LOCALAPPDATA%\DeskCare\deskcare.sqlite3`
- 空白演示数据：`%LOCALAPPDATA%\DeskCare\demo\deskcare-demo.sqlite3`
- 完整演示场景：`%LOCALAPPDATA%\DeskCare\demo\scenario-YYYY-MM-DD.sqlite3`

在设置页使用“清除 DeskCare 全部本地数据”前会再次确认。它会清除本机记录和授权状态，但不会删除程序文件；SQLite 清理不保证清除系统备份、云同步副本或磁盘快照。演示库与正式库分开，但清理正式数据前仍建议确认并导出你要保留的报告。

## 反馈问题时建议提供

- ZIP 文件名、使用便携版还是单文件版，以及 Windows 版本（Windows“设置 → 系统 → 关于”）；新版侧栏底部显示 UI2；
- 复现步骤和不含私人内容的错误文字；
- 使用的是正常模式、空白 `--demo` 还是完整 `--demo-scenario`。

请勿提供 API Key、语音录音、私人任务标题、窗口标题、应用使用明细或健康打卡内容。上述问题说明主要根据当前代码和隔离启动测试整理；除已注明的自动化/启动验证外，托盘、多屏/DPI、SmartScreen 和其他电脑上的运行状况仍需实际设备验收。
