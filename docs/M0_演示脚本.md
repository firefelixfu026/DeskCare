# DeskCare 2.0｜M0 60 秒演示脚本

> 本脚本只演示 M0 已实现能力。页面中的任务、统计和报告均为演示/占位内容，不代表真实用户数据。

## 0–10 秒：产品定位

“DeskCare 是一个本地优先、用户可控的电脑使用习惯辅助工具。它不是医疗诊断器，也不是全天候监控软件。”

启动程序，展示左侧四个页面：今日、使用统计、状态与报告、设置与隐私。

## 10–25 秒：今日页与演示数据

进入“今日”，展示演示任务卡片和下一步建议。

说明：M0 只搭建页面结构；任务导入、用户确认和持久化属于后续里程碑。

## 25–38 秒：默认隐私状态

进入“设置与隐私”，指出：

- 活动监测默认关闭；
- 具体应用名统计、健康打卡和本地 AI 默认关闭；
- M0 不读取窗口标题、键盘内容、文件或网页地址；
- 页面内容明确标记为演示数据。

## 38–50 秒：用户主动控制

点击“开启电脑活动统计”，展示状态从“监测未开启”变为“监测运行中”；再点击暂停，展示“监测已暂停”。

强调：只有用户主动开启后，后续 provider 才允许读取样本；暂停后立即停止读取。

## 50–60 秒：托盘与后续路线

关闭窗口，展示系统托盘中的“打开 DeskCare”“暂停/恢复监测”“退出”。

收尾说明：M1 将在用户确认后接入受控 Windows 采样；任务解析、柔性提醒和事实报告会继续保持独立许可、可解释和可退出。

## 不应在 M0 演示中声称

- 已经读取真实 Windows 活动；
- 已经检测疲劳、视力或健康状态；
- 已经完成任务导入、智能提醒或 AI 推理；
- 演示数据来自真实用户或真实连续监测。
