## Windows 下载体验

下载 **DeskCare-UI13-Windows-x64.zip**，解压完整文件夹后运行 `DeskCare-UI13.exe`。首次体验可运行 `START-DEMO.cmd`，使用虚构任务和统计，不读个人数据库。

已有旧版在运行时，先从托盘退出旧版。包未签名，不建议全局关闭安全防护。核心任务、提醒与本地说明不要求配置 AI。
