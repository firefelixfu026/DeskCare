# DeskCare 历史版本归档

此归档保存本机旧版 dist 运行目录、旧版 release 提交包和安装包。相同文件内容只保存一次，但恢复时保留每个原始相对路径和文件字节；不是只保留最新版本，也没有把不同版本混成一个运行包。

## 恢复

1. 从历史归档发布页下载所有 `DeskCare-Legacy-Archive-partNN.zip`、`Legacy-Archive-Index.json` 和单独提供的 `RESTORE.ps1`、`README.md`，放在同一个文件夹。
2. 使用发布页单独提供的恢复脚本，不必逐个解压 objects；它兼容从不同 PowerShell 环境启动，优先于分包中的早期副本。
3. 在 PowerShell 执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\RESTORE.ps1 -Destination D:\DeskCare-Restored`，目标必须是尚不存在的新文件夹。
4. 脚本从分包读取原文件内容并逐项校验 SHA256，恢复 dist 与 release 下的旧路径；不执行恢复的程序，也不覆盖已有文件。

`Legacy-Archive-Index.json` 记录每个原文件的路径、大小、SHA256、所处分包及所有分包哈希。GitHub 附件也提供服务端哈希。缺少分包或校验失败时停止，不能据此清理本机。

归档不包含个人数据库、日志、密钥、开发虚拟环境或任意未选择文件。发现此类内容的整个候选目录将保留本机，不上传也不删除。build 缓存和测试目录不在这次自动清理范围。

本机清理须在所有附件服务端哈希一致、替代新版可用后另行执行。清理前再次逐文件核对本地快照；文件被改动、目录出现新文件或程序锁定时保留，不强制停止用户程序。源码、Git 历史、新版与用户数据不删除。旧版删除后可按本说明从 GitHub 恢复。
