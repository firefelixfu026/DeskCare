# M10–M11｜Windows 人工验收清单

自动化测试无法替代真实 Windows 菜单主题、麦克风驱动、DPI 和用户操作；建议在日常使用的 Windows 电脑上逐项检查。语音测试前不必联网，也不要使用真实敏感任务内容。

## 桌面伙伴与任务

1. 用项目虚拟环境运行 `python -m deskcare`。在“设置与隐私”开启“显示桌面伙伴”，确认这不会自动打开电脑使用统计。
2. 打开伙伴的“当前情境”下拉框，确认每个选项的文字都可读；依次选择普通工作、专注模式、会议中、阅读中和安静时段。
3. 在伙伴输入框输入一条虚构任务，实际点击“添加任务”；确认任务出现在主窗口和伙伴中。勾选完成后再取消勾选，确认状态同步。
4. 退出并重开应用，确认刚才新增的任务仍在；删除测试任务。
5. 试用 100%/125%/150% 显示缩放、伙伴隐藏/重新打开和窗口拖动。

## 语音输入

1. 未配置语音包时按住“按住说话”，应提示当前语音输入需要语音包，并且可以继续手动输入任务。
2. 如果愿意测试本机语音：先安装可选语音组件并准备兼容的中文离线语音包，再到伙伴中选择该语音包。
3. 按住说一句不含个人信息的话并松开；确认录音停止，文字只出现在草稿框，未点“确认并添加”前任务列表不变化。
4. 确认草稿后检查只新增一条任务。检查 DeskCare 数据目录中没有录音文件；隐藏伙伴或退出时麦克风活动指示应熄灭。
5. 若麦克风权限被拒绝或设备不支持，确认界面说明失败原因且手动添加仍可用。

> 当前版本的语音识别实现为可选本机 Vosk；它不是“语音输入必须本地”的产品要求。尚未接入默认云端语音，也不会要求用户输入语音 API Key。真实麦克风、驱动格式和中文识别质量需要用户电脑实测。

## 统计、文案与 AI 设置

1. 在“使用统计”确认类别名称为中文；具体应用使用时长仍需单独开启。不开启统计时任务功能也应正常。
2. 在“状态与报告”检查“今天的状态”和“今日 / 每周小结”文案；缺少记录时不应显示虚构的 0 分钟或健康判断。
3. 在设置页确认本机 AI/联网 AI 默认关闭；服务地址、模型名称和密钥入口默认收起，展开后仍能正常使用。
4. 若自愿测试联网 AI，请仅使用虚构任务：检查发送前显示目标服务商、所选任务文字和费用/隐私提醒；不确认或取消后不得发出请求。展开完整请求详情，确认其中没有服务密钥、电脑统计或状态打卡。

本轮不包含吉祥物设计和屏幕边缘自动收起；它们保留为后续需求。
