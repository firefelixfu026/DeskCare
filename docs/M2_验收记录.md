# M2 验收记录

## 范围

M2 只实现“今日任务与文件导入”：用户主动选择 `txt/md/csv/xlsx`，生成可编辑草稿，预览后明确确认才写入本地任务库；今日页支持手工增删改和用户主动修改状态。

## 已实现

- SQLite v2 `tasks` 表与增量迁移，保留 M1 数据和授权状态。
- `.txt` / `.md` / `.csv` 单文件导入；只读取文件选择器返回的路径。
- `.xlsx` 单文件导入：只读取第一个工作表的单元格值，不执行公式、不读取外部链接；复用相同列名/行数/预览确认约束。
- UTF-8 与 UTF-8 BOM；严格限制 1 MB 文件、400 字符行和 500 项任务。
- Markdown 勾选项只作为来源提示，不自动把任务写成已完成。
- CSV 必须包含 `title`，截止时间使用 ISO 格式，错误列名、坏行和坏 CSV 会阻止确认。
- 模糊时间、来源已勾选、无截止时间等信息在预览中保留为不确定性提示。
- 草稿可编辑标题、截止时间、预计分钟，也可移除；取消或关闭预览不改变数据库。
- 确认后任务进入“今日”，可手工添加、编辑、删除、切换待处理/进行中/已完成。
- 只保存安全的源文件名，不保存绝对路径、原文件全文或调试日志。

## 自动化证据

在项目虚拟环境中执行：

```powershell
python -m compileall -q deskcare tests
python -m pytest -q
```

M2 开发阶段已覆盖：导入器正常路径、BOM、中文、模糊时间、预计时长、空文件、错误列名、损坏 CSV、重复任务、文件类型限制；任务迁移、确认、取消不入库、编辑、状态、删除和重复确认原子性；导入预览在重复项编辑前后对确认按钮的门控。

截至 M2 原始验收：27 个测试全部通过，包含 M1 数据库升级兼容性测试、导入预览门控和今日任务状态 UI 回归。XLSX 后续补充实现后由当前全量回归重新验收。

Windows 托盘和真实 Win32 采样不在本记录中重复声称已验证；M2 需要用户按演示脚本进行文件选择器与界面人工验收。

后续集成审计补充：用户输入不带时区的 ISO 截止时间会在确认入库时解释为本地民用时间并保存时区偏移；旧数据库中的无时区值读取时做同样处理。提醒服务的 fake clock 查询日期来自传入的 `now`，自动化覆盖无时区截止时间不会与带时区策略时钟发生比较异常。当前全项目回归为 **64 passed**。

后续补齐 P1 XLSX：用户选中 `.xlsx` 后只读取第一个可见工作表，支持 `title`、`due_at`、`estimated_minutes` 三列并复用现有预览确认。解析器不执行公式、不跟随外部工作表链接，限制压缩包与 XML 解压大小、成员数、列数和行数；相关自动化覆盖内联/共享字符串、损坏文件、公式和解压大小拒绝。表格中的日期应填写 ISO 字符串；Excel 日期序列号不会被猜测转换。
