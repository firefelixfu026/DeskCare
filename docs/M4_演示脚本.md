# M4 演示脚本

## 启动

```powershell
python -m deskcare --demo
```

使用包内虚构任务与模拟活动演示；不要选择真实健康记录或真实私人任务文件。

## BodyLog 与日报

1. 打开“设置与隐私”，确认“个人状态打卡”默认关闭，说明它与活动监测独立授权。
2. 打开“状态与报告”，确认未授权时报告写明“未开启状态打卡”，不会给出身体状态结论。
3. 返回设置，主动开启 BodyLog；回到报告页选择“有些不适”并保存今天的自报。
4. 点击“刷新报告”，查看报告中的时间范围、活动覆盖估计、用户确认任务数、提醒反馈和 BodyLog 来源。
5. 指出报告使用本地规则/模板，不是医学报告；活动分钟不是工作质量，自报选项也不是诊断测量。
6. 点击“删除今天记录”，确认报告不再包含这条自报；也可在设置中清除全部 BodyLog。
7. 点击“导出 Markdown”，主动选择一个临时输出路径，打开文件核对内容。

## 周报边界

- 只有少于 3 个有效活动记录日时，周报显示“样本不足，不做趋势判断”。
- 关闭活动监测时，报告不会写成“今天使用 0 分钟”，而是说明无法提供活动统计。
- 没有任务、提醒或状态记录时，报告列出缺失，不补造数字。
- 报告不会因为使用 VS Code、浏览器或任务标题自动判断工作内容、任务完成、疲劳或健康变化。
