# M8 悬浮伙伴与本地语音人工验收

## 隐私边界

- 桌面伙伴默认关闭；可在“设置与隐私”或系统托盘显式开启，也可用伙伴上的“隐藏”关闭。
- 伙伴最多展示今日列表中的前 6 项；勾选仅把对应本地任务标记为完成/待处理。快捷添加由用户主动提交。
- 情境由用户手动选择，不读取窗口标题、输入内容或网页信息。
- 本地语音是可选功能，依赖 Vosk 运行库及用户自行取得并选择的离线模型目录。应用不下载模型，不使用云端 STT 回退。
- 仅按住“按住说话”期间采集默认麦克风，最长 30 秒；PCM 音频留在进程内存，松开即停止采集并转写，不写音频文件或数据库。
- 转写文字仅填入草稿框；只有点击“确认并添加”才会创建任务。关闭窗口/应用会停止采集并清空待处理音频缓冲。
- 录音会把常见采样率、单/多声道和 PCM/浮点输入转换为识别格式；麦克风不可用、权限被拒绝、依赖/模型缺失或格式不支持时，功能失败关闭，不创建任务；手动任务录入仍可用。

## 开发环境

~~~powershell
python -m pip install -e ".[dev,voice]"
~~~

准备 Vosk 中文离线模型，启动 DeskCare，打开桌面伙伴，点击“选择离线语音包”并选择模型文件夹。模型不包含在源码仓库或 Windows 发布包内。Windows 麦克风隐私设置需允许桌面应用访问麦克风。当前实现只支持本地离线识别，并非语音输入必须本地；是否提供更省事的系统/云端语音选项，属于后续产品决策。

## 人工验收

1. 新数据库启动：桌面伙伴隐藏，首次活动监测和应用明细依旧关闭。
2. 从设置开启伙伴，验证可拖动、置顶、托盘开关、伙伴内隐藏；拖到屏幕左右边缘后应收成小芽吉祥物半露状态，点击露出的图案可展开；重新启动后设置中开启的伙伴会恢复。
3. 添加一条任务、勾选完成、取消勾选；核对主窗口今日页和本地状态同步。
4. 改变情境，核对提醒协调器使用选中的情境；不应自动开启活动监测。
5. 未安装 Vosk/未选模型/无麦克风权限时尝试语音：应显示可读失败原因，录音不得落盘，手工录入仍工作。
6. 配置本地模型，按住按钮讲话并松开：采集应停止，识别文字仅进入草稿框；不确认就关闭，任务库不应新增记录。
7. 修改并确认草稿后，检查仅创建一条任务；检查 LOCALAPPDATA/DeskCare 不出现音频文件。
8. 录音中退出应用：进程退出后麦克风指示应熄灭；应用不应在后台继续采集。
9. 试用不同缩放比例、多屏和全屏应用；伙伴可隐藏，不遮挡时应可重新从托盘/设置显示。

自动化测试不模拟真实麦克风、Windows 隐私弹窗或中文识别准确率；这三类必须由人工在目标设备验收。
