# DeskCare UI10：不适记录与行动回顾

日期：2026-10-20。本轮按已确认顺序完成第一个阶段：本人记录 → 自己确认行动 → 自愿补记／回顾。没有加入医院报告上传、症状分析、诊断或治疗建议。

## 打开哪里

先在托盘退出旧版，再打开 `dist/DeskCare-UI10/DeskCare-UI10.exe`，侧栏底部应为 UI10。复制时需要整个 DeskCare-UI10 文件夹，不能只复制 EXE。旧版及 ZIP 保留；本轮不覆盖旧参赛材料。

侧栏“状态与记录”有两个分类：“每日打卡”和“不适记录”。设置 → 提醒与状态中也有“管理不适记录”的入口。

## 作为用户体验这一条流程

1. 进入“不适记录”，阅读说明，主动开启“本机不适记录”。它与每日打卡、使用统计、AI 授权分开，升级不会替你开启。建议先用虚构描述体验。
2. 点“记一下不适”，写一句自己的感受，核对发生时间。部位、自报程度、持续分钟和备注均可留空。默认不预选症状或程度；点“不记录”或取消，不会新增任何记录或任务。
3. 同一天可以记录多次，不会覆盖每日打卡。选中一条后可以编辑，也可以点“加入行动任务”，自己修改行动标题、日期或时间，确认后才加入今日／后续任务。取消则没有任务。
4. 有想补充的内容时再点“补记感受”，选择“感觉减轻／差不多／感觉加重／说不准”，备注可选，不选也可以取消。没有定时追问，不补记不会被认定为正常、康复或改善。
5. 点“查看回顾”，对照原记录、自己确认的行动和各次补记。任务标记完成不等于不适改善；这里不判断病因，也不把电脑时长当作健康测量。

行动任务只是你确认的普通待办，不是医生建议；不会自动挪动原 ddl、调整休息提醒参数或弹出新的定点健康闹钟。行动标题默认是通用文字，不自动复制不适描述、部位或备注。你自己填进任务的内容会像其他任务一样出现在任务页和伙伴面板，请自行决定是否写敏感信息。

## 回看、修正、导出和删除

- 可看近 7 天、近 30 天或全部记录，按窗口高度分页；补录很早的记录后会定位到“全部记录”中相应页面。
- 原记录可编辑；补记填错时，在回顾窗口中选中该次补记，确认删除后重新填写。
- “导出选中”只将你选中的一次记录及其行动、补记保存为本机 TXT；不包含其他事件或电脑活动轨迹，不调用 AI。
- 删除一次记录会同时删除其补记和关联关系；已加入任务的行动保留，可到任务页另删。反过来，删除行动任务不会删除原记录，回顾会显示关联任务已删除。
- “清空记录”保留开关，清空所有不适事件／补记／关联；关闭授权也会清空这部分数据。二者均不删除每日打卡、统计或已确认任务；操作前有默认取消的确认框。
- “清除每日打卡”只影响旧的每日粗粒度选项。“清除 DeskCare 全部本地数据”则包括不适事件、补记、任务和授权状态，并处理程序管理的升级备份。

## 数据与安全边界

不适数据只在本机新表中保存，**不进入现有本机 AI 润色或联网任务整理请求，也不自动并入普通日报／周报**。回顾来自本机确定性拼接，未使用模型，不能宣传为已经实现的医学 AI 分析。

本地数据库没有新增加密或应用口令；请注意 Windows 账号和设备访问权限，不建议在共享账号下写敏感信息。导出的文件、系统备份及自行复制的数据库由你另行保管，应用删除不能删除这些外部副本，不承诺取证级擦除。记录不能替代就医，紧急健康问题不要等待软件回复。

旧库升级使用 SQLite v9 增量迁移，在同目录保存一次 `<数据库名>.before-ui10`（不覆盖已有同名文件）。不会把旧每日打卡翻译成新症状事件，也不新增健康授权。原 UI8 的 `.before-ui8` 备份仍按其原规则保留；全部清除会处理两种受管理备份。

升级后不建议旧版继续写同一个库。若确需回退，请先在 UI10 关闭／清空不适记录；旧版本不能管理新增的健康表，不能依赖旧版“全部清除”删除新表中的内容。
