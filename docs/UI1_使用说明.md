# DeskCare UI1 使用说明

> 历史版本记录。2026-10-20 的 UI2 已移除内置语音输入；当前运行与体验步骤请看 `UI2_使用说明.md`，不要将本文旧版语音步骤用于 UI2。

把 `DeskCare-UI1-windows-x64-portable.zip` 完整解压，进入里面的 `DeskCare-UI1` 文件夹，双击 `DeskCare-UI1.exe`。程序依赖文件在同一文件夹中，请保留整个文件夹。

更新前请从托盘退出旧版本；新包解压到新的文件夹即可，不要混用旧版文件。已有本地记录仍在原来的用户数据目录中。

## 从左边选择要做的事

- **今日任务**：添加或导入清单，编辑并自己标记完成；选择当前工作情境。
- **使用统计**：在“使用概览”查看最近 7 天柱状图和当天类别占比；在“应用排行”查看经你另行授权的各应用时长。图表随新记录更新，鼠标移到柱形或图例上可看时间。没有记录的日期不会冒充已记录的 0 分钟。
- **状态打卡**：单独授权后，记录今天主动选择的简单感受。
- **日报与周报**：查看已经排版的小结；任务、活动和状态记录改变后会刷新，也可以手动刷新或保存为 Markdown 文件。无需自己阅读 Markdown 源码。可选的 AI 润色基于点击时的记录，展示时会注明快照；点击“刷新报告”可回到最新事实小结。
- **设置与隐私**：按“常用设置 / 提醒与状态 / AI 服务 / 数据与隐私”分别管理；无需从一张长页面中找所有开关。

首次活动监测仍默认关闭；任务管理无需开启监测。应用名称、状态打卡和 AI 都继续使用各自的独立开关。图表表示活动时间估计，不代表真实工作时间或健康状态。

语音仍是可选本地功能，发布包包含 Vosk 运行组件但不带中文模型；没有配置时可手动输入任务。

本次为原生 Qt 界面更新，不含 Live2D。包未签名，系统可能显示未知发布者提示；请确认来源和校验值，不要为运行程序而关闭系统防护。详细故障说明见同包的《Windows_常见问题与故障排查.md》。

## 演示与验证边界

开发演示仍支持启动参数 `--demo-scenario`，使用独立、明确标注为虚构的数据。离屏预览图片同样只使用虚构数据。

本轮已执行代码回归和离屏视觉检查，没有启动用户桌面上的新版程序。实际 Windows 启动、托盘、真实 DPI/多屏、麦克风和普通用户体验仍需人工确认。
