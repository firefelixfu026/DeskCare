# M5 验收记录

## 范围

M5 处理本地长期运行与可交付基础：单实例、数据清除、Windows onedir 构建入口、安装/卸载说明和可复现的合成策略对照。M5 不改变 M1-M4 的数据含义，也不增加网络、自动启动或后台服务。

## 已实现

- `SingleInstanceGuard` 使用 Qt 本地 IPC；第二次启动只向已有进程发送显示请求，不重复启动采样器或数据库业务层。
- 无系统托盘时仍保持可见窗口可退出；有托盘时关闭窗口进入托盘，托盘打开请求可恢复窗口。
- 设置页提供“清除 DeskCare 全部本地数据”，二次确认后删除活动、任务、提醒反馈、BodyLog 和授权状态，保留数据库 schema，不删除程序文件。SQLite 连接启用 `secure_delete`，全部清除后尽力执行 `VACUUM`；界面明确系统备份/快照仍可能保留副本。
- `scripts/build_windows.ps1` 使用专用顶层 launcher 提供 Windows PyInstaller `--onedir --windowed` 构建入口并携带 `assets`，避免冻结包执行包内相对导入入口；另提供 `-OneFile` 作为单文件分发备选。
- `scripts/run_baseline.py` 使用固定虚构情境，对比固定 40 分钟提醒和上下文策略，输出动作与 reason code；脚本明确不宣称哪种方式更健康或更高效。
- README 补充依赖安装、onedir 运行、卸载、本地数据目录和离线基线命令。

## 自动化证据

```powershell
python -m compileall -q deskcare tests scripts
python -m pytest -q
python -m pip check
python .\scripts\run_baseline.py
```

当前含 M6 回归在内的 E 盘项目测试为 **64 passed**；`pip check` 通过；基线脚本可直接从项目根目录运行，输出 7 个合成场景、固定基线 6 次提醒和上下文策略 2 次软提醒。这个数字只是代码行为对照，不是用户研究结论。

无头 Qt 冒烟验证四页、默认活动与 BodyLog 关闭、BodyLog 保存/删除和窗口装配。单实例守卫已有 Qt 单测。Windows 11 + Python 3.12.7 + PyInstaller 6.22.3 已实际构建 onedir/onefile；自动验收用隔离 `LOCALAPPDATA` 启动两个包到 `DeskCare` 主窗口并检查无 `Unhandled exception`。

## 隐私与安全检查

- 单实例 IPC 只发送 `show` 控制消息，不传输活动、任务、健康数据。
- 全部清除是用户主动操作并二次确认；自动化测试验证唯一任务标记在 `secure_delete` + `VACUUM` 后不再出现在数据库文件字节中。README 仍明确系统备份/快照不等同法证级擦除。
- 没有自动启动、后台服务、网络遥测或云端同步。
- 构建脚本只打包程序和公开图标资源，不扫描用户目录。
- 设置页使用垂直滚动容器，短窗口下底部隐私与清除控制仍可访问。
- 全部清除后会立即刷新任务与报告页面，并清空提醒服务在内存中的冷却/反馈状态；不会出现数据库已空但 UI 仍显示旧内容的假象。

## 尚未实现/风险

- 尚未在 Windows 10/11 不同 DPI、锁屏、睡眠唤醒、托盘通知和权限条件下完成全矩阵人工验收。
- 当前同时提供 onedir 与 onefile，仍未提供代码签名安装器。
- M6 接口已实现，但当前本机 Ollama 模型列表为空，真实模型输出质量仍待人工验收。
