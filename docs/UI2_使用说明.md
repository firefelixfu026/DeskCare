# DeskCare UI2 使用说明

## 打开新版

先在系统托盘右键 DeskCare，选择“退出”，再打开 `DeskCare-UI2/DeskCare-UI2.exe`。侧栏底部应显示 `DeskCare · UI2`；如果仍是旧界面，说明旧实例尚未退出。

便携 ZIP 请完整解压到新文件夹，不要单独复制 EXE，也不要混用旧版 `_internal`。UI2 仍使用原有本机数据库，不需要重新导入任务；首次使用的各项授权仍默认关闭。旧版程序目录保留，但不要同时运行。

## 这次可以直接体验什么

1. **添加任务**：今日任务 → 添加任务。弹窗为浅色、文字清晰，按钮是“添加/取消”；预计用时的数字箭头不再出现原生黑框。
2. **切换情境**：点击“普通工作”右侧箭头，选择会议、专注或阅读；主窗口和悬浮伙伴的选择保持同步，不会因此开启统计。
3. **看统计**：在已由你开启统计的情况下，使用概览会随本机聚合更新。柱形高度、环形占比和数字从上一状态过渡，不会每几秒重新从零出现。相同数据不重启动画；类别颜色不因排序变化而互换。
4. **记录状态**：单独授权后，在状态打卡页保存今天的选项，并查看最近七天记录。没有记录的日期显示“—”，不会补成舒适或不适。删除今天记录需要确认，随后列表和日报更新。
5. **用桌面伙伴**：设置与隐私 → 常用设置 → 显示桌面伙伴。它现在只保留情境选择、今日任务勾选、全部任务和快捷添加；按回车也能添加。拖动标题到屏幕左右边缘，仍可收成圆形半露伙伴。

内置语音转文字已移除。不再录音，不需要安装语音库或选择模型，也没有转写草稿框。升级只删除不再使用的语音模型路径设置，不删除已有任务或你自行下载的模型文件。系统听写由 Windows 自己管理，DeskCare 没有替用户开启或测试系统听写。

界面删去了重复口号和图表下的说明文字；必要的授权、删除确认、演示标识、报告估计值和医学边界仍保留。

## 本轮验证边界

UI2 通过离屏自动化与虚构数据截图检查；没有在用户桌面启动 EXE、点击托盘或操作真实麦克风。真实 Windows 主题、缩放、多屏与长时间使用仍需体验。程序是未签名便携包，不提供 Live2D 或自动更新。
