# DeskCare UI8 使用说明与本轮记录

更新日期：2026-10-20。当前程序为 `dist/DeskCare-UI8/DeskCare-UI8.exe`，复制时需要整个 DeskCare-UI8 文件夹，不能只复制 EXE。程序未签名。旧版和旧归档保留。

## 先打开新版

在系统托盘中退出旧版 DeskCare，再打开 UI8；侧栏底部应显示“DeskCare · UI8”。直接双击新版而旧版未退出时，单实例机制可能只唤起旧窗口。

本轮没有替你关闭正在使用的程序、修改真实授权或迁移真实数据库。以下自动化界面截图都使用临时库与虚构数据。

## 看每小时的使用情况

1. 设置与隐私 → 常用设置，主动开启“按小时汇总使用时间”。电脑使用统计也需要开启；小时开关本身不会自动开启监测。
2. 正常使用电脑片刻，进入使用统计 → 每天 → 使用概览。当天图表按 0:00–24:00 展示活跃时间估计；纵轴通常是每小时 0–60 分钟。鼠标停在柱子所在区域可看对应小时的时长。
3. 用前一天／后一天查看历史；选择每周查看周一至周日，使用前一周／后一周翻看，或点回到今天。应用排行与类别占比跟随所选日期范围，应用较多时翻页。

小时记录从授权后开始，不会将升级前的每日总量平均摊开。未采集的小时是“无记录”，不是使用 0 分钟；仅观测到空闲的小时可以有 0 活跃分钟。暂停、关闭监测、锁屏／休眠长空档和明显校时边界不会补算成使用。图表复用已有动画状态更新，不每轮从零重画。

只保存每小时的粗粒度类别时长，不保存逐秒活动、应用标题、输入内容、网页或文件路径。小时数据与具体应用名称是两项独立授权；本版不提供逐应用的小时轨迹。最近 30 个日期以新记录写入时清理的方式保留；没有新采集时不会运行后台清理任务。撤回小时授权会清除已有小时记录，原每日汇总不因此删除。“清除电脑使用记录”同时清除日汇总、应用汇总与小时汇总。

## 任务里的日期、ddl 与预计用时

- Markdown／文本中的 `10.20`、`## 10.21` 等日期标题提供该段任务的安排日期。没有年份时使用当前年份，并在预览提示核对；跨年清单请明确写年份。
- `准备材料（ddl 23:00）` 将标题与截止时间分开；`ddl 24:00` 是该日期结束、次日零点。
- `交流（19:00–20:00）` 是活动时段，不偷换成截止时间；明确时段可得出 60 分钟。`暂定下午` 原样保留为时间说明，不猜具体钟点。
- 用户已写的预计用时优先；缺少时，联网／本地 AI 可给出可修改的预计分钟，标记“建议”，不当作实际耗时。没有配置模型时，规则不会伪装成 AI 估计。
- 模型候选会与原文重新对照，原清单可识别的日期／ddl／时段不会被模型清空；模型遗漏的原任务仍保留。预览确认前不入库，模糊表达和年份仍需核对。

这是本轮对示例格式的实现及自动化验证，不承诺所有自然语言、表格、多时区和真实模型输出都能正确识别。CSV／XLSX 仍遵循原严格列格式；新的短日期标题主要适用于 Markdown／文本。不会自动扫描其他清单。

## 今日、后续与自己的备注

任务列表现在占用剩余窗口空间，按窗口高度分页，不需要在很短的内层列表里滚动。卡片顶部切换“今日任务／后续任务／全部任务”。今日包含当天安排及逾期未完成，未来安排放在后续；新建或编辑后会定位到相应列表和分页。

右键某一行，可编辑任务与时间、查看／编辑备注、安排到今天或其他日期。备注是你写的内容，不显示内部 `model_suggestion` 代码。导入预览中的“我的备注”也可以填写。安排日期与真正的截止时间／活动时间分开，挪到今天不会偷偷修改原 ddl。

旧版已经丢失的日期无法从任务标题凭空恢复。请重新选择原清单核对，或右键编辑原任务；重复导入会提示“新增而非覆盖”，默认不继续。若确实要重导，请先核对并自行处理旧条目，避免两份任务。新版不会自动批量删除旧任务。

## 提醒间隔

设置与隐私 → 提醒与状态，在分钟输入框中直接输入 13、27 等任意 1–180 的整数，按回车或离开输入框保存。默认仍为 40 分钟。按累计活跃时间择机提醒，会议／安静模式、暂停和未开启统计时不提醒；不是保证到点必弹的墙上时钟。

可先点“试一下提醒”体验卡片，不会写入真实反馈。后台焦点、全屏／多屏、原生托盘、真实长期运行仍需要实际使用验证。

## 数据升级与验证边界

UI8 首次打开旧库时执行增量迁移，保留已有任务、统计和授权；已有库迁移前会在同目录保存一次 `<数据库名>.before-ui8`，不覆盖同名备份。备份也包含旧的本地隐私数据。“清除全部本地数据”同时清空此受管理备份里的记录；文件系统快照或你另存的副本不在控制范围，也不声称取证级擦除。回退旧版不能完整识别 UI8 新增字段，使用前请保留自己的备份。

本轮测试覆盖授权默认关闭、跨小时／午夜分桶、未授权不回填、暂停门控、撤回删除、30 天写入清理、明显系统时钟跳变、来源时间保护、备注持久化、后续任务、分页、历史日／周与任意分钟。真实 DeepSeek 推理质量、用户这份完整清单的逐项结果、原生 Windows 焦点／多屏／托盘、干净电脑和长时跨天运行仍待验证。没有读取密钥或调用付费接口。
