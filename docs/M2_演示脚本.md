# M2 演示脚本

## 启动

在项目根目录执行：

```powershell
python -m deskcare --demo
```

`--demo` 只影响活动 provider；任务导入仍使用用户主动选择的本地文件。

## 60 秒演示

1. 打开“今日”，点击“导入清单”。
2. 选择 `examples/今日清单.md` 或 `examples/tasks.csv`。
3. 在预览表中编辑一个标题，确认 `16:00` 被标为需人工确认日期，查看来源勾选项没有自动变成已完成。
4. 点击“确认导入”，回到今日页查看任务。
5. 用状态下拉框主动改为“进行中”或“已完成”。
6. 选择任务并测试编辑、删除；删除前会再次确认。
7. 再次选择一个文件后直接关闭预览，确认今日列表没有新增任务。

## 边界演示

- 空文件、非 UTF-8 文件、损坏 CSV、缺少 `title` 或包含未知列时，预览显示清晰错误且不能确认。
- 重复标题必须编辑或移除后才能确认。
- 未开启活动监测时，任务管理仍可使用；任务状态不由电脑使用行为自动改变。

演示任务和活动数字均为虚构/模拟输入，不代表真实用户数据或健康结论。
