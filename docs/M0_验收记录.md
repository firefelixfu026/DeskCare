# DeskCare 2.0｜M0 验收记录

**阶段**：M0 项目初始化与可运行基础界面  
**记录日期**：2026-10-14  
**运行时**：Python 3.12.7、PySide6 6.12.0、pytest 8.4.2

## 已验证

- 项目目录中未发现 DeskCare 1.0 代码；交接包中的规范、文档和虚构示例已保留。
- `python -m deskcare` 可以创建 Qt 应用、显示主窗口并进入事件循环。
- 主窗口包含“今日”“使用统计”“状态与报告”“设置与隐私”四页。
- 系统托盘可用时支持打开、暂停/恢复监测和退出；不可用时关闭可见窗口仍可退出。
- 首次启动活动监测、具体应用名统计、健康打卡和本地 AI 均为关闭状态。
- FakeActivityProvider 是唯一的 M0 provider，不访问 Windows 活动、用户文件或网络。
- 未授权或暂停时，MonitoringController 不读取 provider。
- Qt 可加载 `assets/deskcare-app-icon.png`；资源缺失时使用代码绘制 fallback。
- `python -m compileall -q deskcare tests` 通过。
- `pytest -q` 的 6 项断言全部通过，输出 `...... [100%]`。

## 尚未验证/明确不属于 M0

- 尚未在 Windows 10/11 实机验证真实 Win32 采样、锁屏、睡眠唤醒和托盘通知。
- 尚未实现真实系统监测、SQLite、任务文件导入、提醒策略、健康打卡、报告生成、LLM 或 PyInstaller 打包。
- 测试宿主在 pytest 输出完成后存在进程回收延迟；这不影响已执行断言，但暂不把它表述为稳定的退出码 0。

## 隐私边界复核

M0 不读取键盘内容、窗口标题、网页 URL、剪贴板、截图、摄像头、麦克风或未选择文件；不调用网络模型；所有页面中的任务和统计均明确标记为演示/占位内容。
