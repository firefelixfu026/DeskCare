# M9｜可选云端任务 AI：隐私说明与人工验收

## 功能边界

- 默认关闭，且与活动监测、应用明细、BodyLog、本地 AI 分别授权。
- 唯一云端功能是用户主动选择任务清单后的候选任务解析；不会处理报告或自动上传历史任务、活动和健康数据。
- 每次请求都显示目标 HTTPS Endpoint、模型和完整 JSON 请求正文。只有点击“确认发送”才发出请求；取消则不联网。
- API Key 用 Windows Credential Manager 通用凭据保存，不写入 SQLite、日志或导出。关闭云端授权会尝试删除凭据；若 Windows 凭据删除失败，界面应明确报告错误，用户可在 Windows 凭据管理器中检查 `DeskCare/CloudAI/OpenAICompatible`。
- 云端响应只生成可编辑草稿；仍需用户检查并点“确认导入”才写入任务库。联网失败、超时、响应不合规时原规则草稿保留。
- 只支持 HTTPS Endpoint。自定义兼容服务仍由用户自行核验其隐私条款、保留策略、计费和数据处理地区。

## 自动化验证（不使用真实凭据）

```powershell
python -m pytest -q tests/test_m9_cloud.py
```

测试用进程内模拟凭据与传输，**不会连接互联网**，不验证 Windows Credential Manager API 或特定服务商的兼容性。

## Windows 人工验收（可跳过云端实测）

1. 首次运行打开“设置与隐私”，确认云端 AI 默认关闭、Key 状态为空；无需网络即可使用任务和其他本地功能。
2. 尝试开启授权后选择“否”，确认开关仍关闭。确认授权只说明数据边界，不应发出网络请求。
3. 如愿意实测：先核实服务商隐私/计费政策，再配置其 HTTPS Chat Completions-compatible Endpoint 和模型名；在授权开启后通过密码输入框保存自己的 Key。不要把 Key 发给开发者或写入清单文件。
4. 选择一个不含个人/健康信息的虚构任务清单，点击“云端 AI 提议”。检查预览 Endpoint、模型和完整正文仅含刚选清单及固定任务解析指令；确认未出现活动统计、应用名、BodyLog、报告或 API Key。点取消后应没有请求。
5. 再次操作并确认发送，检查结果仍可编辑；关闭导入窗口或取消不得写入任务。只有显式确认导入才入库。检查原规则草稿在云端失败/无效响应时仍可用。
6. 在设置关闭云端授权，检查提示成功并显示 Key 已删除；重新打开授权后 Key 状态应为空。可在 Windows“凭据管理器 → Windows 凭据”检查目标凭据已移除。
7. 可选：设置错误/不可达 Endpoint，确认失败提示不展示 Key、请求体或服务商原始响应；其他功能不受影响。

**安全提示：**实测需用户自行承担外部服务的数据处理、计费与网络风险。若不愿把清单发往云端，可只使用规则解析/本地 AI，或完全关闭云端功能。
