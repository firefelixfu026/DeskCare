```powershell

```

本清单只验证 M1 的活动采样、暂停控制和本地统计，不验证任务导入、提醒策略、健康判断或 AI。

## 检查项

1. **首次/未授权状态**
   - 打开“设置与隐私”，确认“开启电脑活动统计”未勾选时，使用统计页显示“未开启/暂无数据”。
   - 不应出现虚假的“0 分钟”；此状态不读取 Windows 活动。

2. **用户主动开启**
   - 勾选活动统计，等待至少两次采样周期（默认约 10 秒）。
   - 使用统计页应显示电脑活动时间估计，以及可能的 `CODE / BROWSER / OFFICE / OTHER / UNKNOWN` 类别。
   - 类别是粗粒度估计，不应显示窗口标题、网页地址、文件名或完整进程路径。

3. **暂停边界**
   - 点击“暂停监测”，等待 10 秒，再恢复监测。
   - 暂停期间不应累加活动；恢复后应从新的采样基线开始，不把暂停间隔补记为活动。

4. **锁屏/唤醒**
   - 已开启监测时锁定 Windows，等待超过 60 秒后解锁。
   - 统计不应因为锁屏时长突然增加；下一次有效采样从新会话开始。

5. **托盘与退出**
   - 关闭主窗口，确认程序进入托盘而不是继续显示主窗口。
   - 从托盘打开窗口、暂停/恢复监测。
   - 点击“退出”后确认进程结束；退出后不应继续采样。

6. **清除本地统计**
   - 在“设置与隐私”点击“清除已保存的活动统计”。
   - 未确认时数据不变；确认后统计页立即清空。
   - 清除活动数据不应偷偷改变监测授权状态。

## 伦理边界

活动分钟只是有限的电脑活动估计，不等于真实工作时长、学习质量、疲劳、视力或健康状态。锁屏、无输入和空闲状态也不能被解释为“确实休息”。
