# UI7：提醒与 DeepSeek

2026-10-20。先从托盘退出旧版，再运行 `dist/DeskCare-UI7/DeskCare-UI7.exe`，确认左下角 UI7。保留完整目录，不能只复制 EXE。旧版本和真实用户库不覆盖或清除。

## 先体验提醒，不用等

进入“设置与隐私 → 提醒与状态”，点“试一下提醒”。应在屏幕右下角显示可关闭的小卡片，不锁屏、不自动打开主窗口。预览可以在未开启统计时手动体验，不采样，不改授权，不写提醒和反馈记录，也不改变计时。

将“大约多久提醒一次”改成 25、40 或其他值，范围 5–180 分钟，自动保存；重开后保留。该数值是使用偏好，不是医学建议。

自动提醒仍需你本人开启电脑使用统计，且没有暂停。它按累计活跃时间选择时机，而不是精确的墙上时钟：短于约五分钟的无输入间隙保留此前进度，不把空闲分钟添加为活跃；长时间无输入、未知/锁屏、休眠长间隔、暂停或关闭时重新计时。原使用统计的“连续活跃”仍按原有定义，不因提醒更改。

普通情境下到间隔后等待应用切换或你确认完成任务等空档；若一直没有空档，额外约五分钟后给出轻量提醒。专注和临近截止也最多在这段窗口内延后；会议和安静模式仍完全抑制自动提醒。可选的反馈个性化可能将候选间隔延后五分钟，设置页会显示状态。

提醒同时显示在今日页和独立桌面卡片，主窗口收进托盘后仍有独立呈现通道。没有声音、不调用系统通知服务、不自动抢焦点。每条提醒只弹一次，保留到你操作，不连续叠窗：

- “现在休息”和“跳过/关闭”开启新的累计周期；前者只是休息意愿，不表示已完成休息。
- “10 分钟后”保留已到期进度，冷却到期再择机提醒，而非再等待整轮间隔。
- 今日页仍保留“时机不合适”等反馈；暂停或关闭统计会立即隐藏实际提醒。

## DeepSeek 地址怎么填

在“设置与隐私 → AI 服务”保存：

- 服务地址：`https://api.deepseek.com/chat/completions`
- 模型名：`deepseek-flash`
- 密钥：只在应用内输入自己的 DeepSeek API Key，不发到聊天或截图。

UI7 也接受 `https://api.deepseek.com`、尾部斜杠及 `/v1` 根地址，自动补全完整路径；重启时兼容旧保存值，不更换主机、不允许重定向携带密钥。其他服务商地址不自动改写。

DeepSeek 请求显式使用非思考模式及 JSON 输出，设定 4096 个最大输出 token，等待网络操作的超时为 60 秒。模型请求正文参数都在发送前预览中，不会在确认后偷偷增加。较长清单可拆分；超限/格式错误时保留原草稿，不自动重试产生多次费用。使用统计和状态不发送。

HTTP 400（参数/格式）、401（密钥）、402（余额）、404（路径或模型）、429（限流）及服务异常分别提示；网络、超时、TLS 失败也单独说明。错误不显示服务商响应原文、密钥或任务正文，不关闭证书验证。

官方核对来源：[首次调用](https://api-docs.deepseek.com/quick_start/pricing-details-cny/)、[聊天接口](https://api-docs.deepseek.com/api/create-chat-completion/)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)。2026-10-20 核对支持 deepseek-flash；这不是本机已经完成真实推理的证明。
