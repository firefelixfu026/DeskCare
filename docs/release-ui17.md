## DeskCare UI17｜柔和选择与提醒反馈

- 常用情境、日／周和报告类型改为圆角分段按钮；其他列表统一自绘圆角浮层、柔和选中态和轻阴影。
- 桌面休息提醒补齐“时机不合适”，与“现在休息／10 分钟后／跳过”共同显示。
- 推迟、跳过、明确不合适分开统计；开启反馈建议后，同情境连续 3 次推迟会建议复核频率，不自动改间隔、不推断健康状态。
- 维持本机完整最新版和固定 `Start-DeskCare.cmd` 入口，本机使用者无需重复下载。

其他设备可完整解压 `DeskCare-UI17-Windows-x64.zip` 后运行 `DeskCare-UI17.exe`；启动前退出旧版。附 `START-DEMO.cmd` 隔离演示入口。本包未签名，请勿全局关闭安全防护。
