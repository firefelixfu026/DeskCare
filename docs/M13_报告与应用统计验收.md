# M13 报告与应用统计验收

使用虚构或普通示例数据。应用名称统计和状态打卡均是独立授权；不需要为验收启用云端 AI。

## 自动化覆盖

- 应用明细只有在“活动监测”和“应用名称统计”都开启时才进入报告事实表。
- 未开启应用名统计时，报告仍可展示中文类别汇总，但不读取或显示具体应用名。
- 获授权时展示应用名称与估计时长；文案说明应用时长不代表具体任务或完成情况。
- 本机 AI 报告改写不会接收状态打卡或具体应用名称；AI 结果后仍附有完整事实报告。

## Windows 人工验收

1. 关闭“活动监测”，再刷新日报/周报：不显示虚构的活动分钟或应用明细。
2. 开启活动监测但保持“应用名称统计”关闭：类别使用中文，报告说明未单独开启应用名称统计；不能出现具体应用名。
3. 分别开启两项授权并产生应用统计后刷新：可以看到常用应用及估计时长，并说明这不代表任务内容或完成状态。
4. 撤回应用名称统计授权后刷新：应用明细不再显示；类别汇总仍按活动统计授权状态显示。
5. 如果已配置并主动启用本机 AI，点击“AI 帮我润色”：上方是本机生成的摘要，下方仍保留完整事实小结、数据范围与来源说明。未配置 AI 时模板报告照常可用。
6. 导出报告并核对导出内容与界面事实报告一致；不要把真实健康记录或个人应用使用明细提交到仓库。

本机模型输入中不包含健康状态打卡或具体应用名；云端 AI 仍只用于用户主动选择并逐次确认的任务解析，不处理报告。
