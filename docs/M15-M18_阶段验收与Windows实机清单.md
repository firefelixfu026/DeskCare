# M15–M18 阶段验收与 Windows 实机清单

本文区分“代码和自动化测试已证明”与“还需要在用户 Windows 上实际确认”。自动化测试不能代替麦克风、DPI、托盘和真实打包运行检查。每项实机测试均使用虚构任务；不需要上传私人任务、健康信息或应用明细。

## M15｜主流程可用性与异常路径

自动化覆盖：今日任务新增/编辑/删除、任务导入取消/确认、语音识别结果先作为草稿、用户确认后才保存、数据库重启后读取提醒上下文、错误导入和报告导出应显示可读提示。

Windows 实机验收：

- [ ] 从开始菜单或 `python -m deskcare` 启动；托盘打开、隐藏、暂停/恢复和退出均符合预期。
- [ ] 新增、编辑、完成/撤销完成、删除任务；关闭再打开后核对已保存结果。
- [ ] 逐一导入 TXT、MD、CSV、XLSX 虚构清单；预览后取消时不写入，确认后只写入一次。测试重复任务、空文件、损坏文件和正在被其他程序占用的文件。
- [ ] 悬浮伙伴切换 5 种情境；情境改变不应自动开启活动统计。
- [ ] 无语音包、拒绝麦克风权限、无可用设备时，仍可手动输入；语音转写先留在草稿，未确认前任务列表不变化。
- [ ] 录音过程中撤销麦克风权限或断开输入设备；确认录音停止、界面提示可理解、未确认音频不进入任务或文件，之后仍可手动输入。
- [ ] 检查报告导出成功提示；选择只读目录或无效路径时应用不崩溃，原有记录不受影响。
- [ ] 退出时正在录音或识别，确认麦克风停止且应用可正常退出。

## M16｜跨模块一致性与提醒依据

自动化已覆盖导入确认任务 → 活动汇总 → 规则提醒 → 用户反馈 → 任务完成 → 状态打卡 → 重启数据库 → 报告事实一致性。提醒事件增加了最小化决策依据：规则版本、提醒情境、授权/暂停、活跃时长、空闲状态、切换信号、任务完成信号、粗略截止时间区间、冷却状态和生效阈值。

- [ ] 在“状态与报告”对照任务完成数、使用时长、提醒反馈与手工状态打卡。
- [ ] 模拟/测试模式下数据明确标识，不要把模拟值当成个人真实趋势。
- [ ] 关闭应用重开后，已有任务和提醒反馈仍与报告一致。
- [ ] 未授权应用名称统计时，报告和界面不应显示具体应用；关闭活动统计时，提醒不得继续出现。
- [ ] 确认报告没有任务标题、窗口标题、键盘内容或麦克风录音。

提醒决策留痕不保存任务名称、应用名称、准确截止时间或屏幕内容；用于复核规则的上下文只在本机保存。数据库旧版本升级后旧提醒记录应保留，且上下文为空而不是臆造。

## M17｜普通用户表达与理解

- [ ] 让一位未参与开发的学生或上班族独立完成：添加任务、选择情境、开启/关闭统计、看懂今日报告。
- [ ] 不解释术语时，确认对方能理解“活跃时间估计”“应用名称统计”“本机 AI/联网 AI”的差别与授权后果。
- [ ] 确认所有统计类别都显示中文；遇到未知应用时不显示生硬英文类别代码。
- [ ] 确认提醒建议是可选的生活提示，不会被理解为诊断、治疗或医学结论。
- [ ] 记录用户卡住的具体页面、按钮和原话，再据此改文案；本项尚需真实用户反馈，开发者自评不视为通过。

## M18｜演示数据、Windows 包与项目交接

- [ ] 普通模式、`--demo` 空白演示和 `--demo-scenario` 完整场景使用不同数据库位置；在演示中产生/查看数据不会污染个人正式数据或报告。
- [ ] 启动 `--demo-scenario` 后核对有两项示例任务、约 40 分钟活动、一次提醒反馈、一项主动状态记录和演示日报；主窗口与报告均能辨认虚构数据。
- [ ] 同一天重复启动 `--demo-scenario`，确认任务/提醒/状态记录未重复增加；报告仍显示完整 40 分钟。午夜边界由自动化测试覆盖，不需要更改系统时钟。
- [ ] 演示报告不被描述为真实用户数据、健康效果或 AI 个性化结论。
- [ ] 在无 Python 开发环境的干净 Windows 用户目录中解压 onedir 包并运行；onefile 包也单独试启。
- [ ] 安装目录无写权限时，应用仍将用户数据写入用户数据目录；更新包不覆盖数据库。
- [ ] 多显示器和 100%/125%/150% 缩放下检查主窗口、托盘菜单、贴边圆形伙伴、隐藏/恢复和拖动。
- [ ] 在另一台普通 Windows 电脑完成首次启动、默认授权关闭、任务流和报告流的 10 分钟演示。
- [ ] 确认 README、产品说明、架构说明、隐私说明、发布包步骤和测试报告相互一致。

## 当前已知边界

- 本轮代码测试可在仓库环境运行；真实麦克风、Windows 权限提示、托盘、真实 DPI/多屏、干净用户目录和普通用户可理解性仍需用户/目标机验收。
- 当前桌面伙伴是 Qt 绘制的圆形小芽，不是 Live2D；本项目不含 Live2D 模型和动画运行时。
- 网络 AI/本机 AI 均为可选项；本次迭代未执行真实服务商请求、未保存真实 API Key，也未下载语音模型。
- DeskCare 的产品定位是“任务 + 温和休息提醒 + 可选本地使用回顾”的整合方案；这属于产品方向，不代表临床效果或已验证的健康收益。
