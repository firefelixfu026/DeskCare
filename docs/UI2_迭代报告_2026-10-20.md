# DeskCare UI2 迭代报告

日期：2026-10-20。依据用户本轮五张截图和六项意见，范围为界面修复与内置语音功能移除；没有新增监测、云服务或医学推断。

## 已完成

| 用户反馈 | 本轮处理 |
| --- | --- |
| 下拉/数字箭头有黑框 | 使用 Fusion 控件风格与统一浅色调色板；使用项目内 SVG 箭头，去除原生子控件边框 |
| 任务弹窗黑底、文字不清 | 全局浅色弹窗/消息框；明确文字与输入框颜色；“添加/保存/取消”中文按钮和次级按钮样式 |
| 环形图接缝、刷新跳动 | 平直弧端与累计角度取整；保留当前帧、数值和坐标轴插值；重复数据不重启动画；中途更新从当前帧续接；按类别保持颜色；同名应用时长合并而非覆盖 |
| 状态打卡空旷 | 今日记录摘要 + 最近七天自主记录，限宽并支持滚动；未记录保留缺失，未授权不查询/展示历史 |
| 不必要的小字 | 移除侧栏口号、页面导语、重复图表说明和伙伴语音说明；保留必要隐私授权、删除确认与报告事实边界 |
| 悬浮窗复杂且语音不需要 | 精简为任务/情境/快捷添加；保留圆形贴边交互；删除录音、转写、模型选择、Vosk 适配及音频转换代码 |

## 数据与隐私

- 复用原有数据库、任务、提醒、监测和报告服务，不重建用户数据。没有读取真实用户数据库或录音。
- 仅移除废弃 `voice_model_path` 设置，不删除任务，也不扫描/删除用户下载的模型目录。
- 本轮构建排除 Vosk 和 QtMultimedia；既有开发虚拟环境内已安装的软件不做卸载。
- 应用明细撤回后立即清空图表；已清空的活动观察也立即去除旧图形，不用动画拖延隐私清除。
- 健康自报仍独立默认关闭；七天列表只回放用户保存过的选项，不作评分、诊断或补全。

- 全量：`python -m pytest -o addopts= -q -rs -p no:cacheprovider --basetemp .pytest-ui2-final-merged`，Qt offscreen：**121 passed, 1 skipped，39.85 秒，退出码 0**。跳过项为受限环境禁止的本机 AI socket 探测。
- 150% Qt 缩放：界面、任务、伙伴、报告和新回归测试 **32 passed，13.56 秒**。
- 新增九项 UI2 回归，覆盖中断续接、相同数据不重启、稳定颜色、坐标轴过渡、缺失与零区分、授权清空、同名应用累计、暗色系统下弹窗可读性、状态保存/删除/授权历史门控。
- 根据语音功能移除，删除不再适用的录音/转写测试；保留伙伴任务、持久化、情境、贴边测试，并增加无语音入口且不删除任务的回归。没有用删除失败测试来规避现存功能问题。
- `python -m compileall -q deskcare tests scripts`、`python -m pip check`、`git diff --check` 均通过。
- `python -m scripts.preview_ui ... --width 1040 --height 680` 与 `1240 × 820` 使用临时数据库、FakeProvider 和虚构任务生成预览，逐页检查；无托盘、实际系统采样或可见桌面操作。

## 文件与交付

主要代码：`deskcare/ui/theme.py`、`charts.py`、`pages.py`、`main_window.py`、`task_dialog.py`、`companion.py`、`deskcare/app.py`；资源为 `assets/chevron-*.svg`；构建和预览脚本、测试、依赖声明及当前说明同步更新。

移除：`deskcare/voice/` 三个源文件和已失效的 `tests/test_voice_audio.py`。Git 历史可追溯，旧发布包不覆盖。

新发布目标为 `dist/DeskCare-UI2/DeskCare-UI2.exe` 与 `release/DeskCare-UI2-windows-x64-portable.zip`；实际归档校验、大小和 SHA-256 以 `RELEASE_MANIFEST.md` 的 UI2 记录为准。
