# DeskCare M18r1 运行说明（Windows）

## 直接运行

- **便携版**：完整解压 `DeskCare-M18r1-windows-x64-portable.zip`，再进入解压目录内层的 `DeskCare-M18r1` 文件夹，运行 `DeskCare-M18r1.exe`。不要只复制 exe；请保留整个程序文件夹。
- **单文件版**：完整解压 `DeskCare-M18r1-windows-x64-onefile.zip`，运行解压目录中的 `DeskCare-M18r1.exe`。
- **开发版**：在项目根目录运行 `python -m deskcare`。

首次打开时，电脑使用统计默认关闭。使用任务清单不需要开启统计。M18 发布包包含 Vosk 语音运行库，但不包含中文语音模型；语音未配置时可直接手动输入任务。若要试演示模式，在 PowerShell 中进入 exe 所在目录后执行：

```powershell
.\DeskCare-M18r1.exe --demo
```

演示模式使用模拟活动，并写入独立的 `DeskCare/demo/deskcare-demo.sqlite3` 数据库；不要将模拟数据当成个人真实记录。桌面语音模型不包含在发布包内，未选择模型时仍可手动输入任务。

需要直接讲解完整产品流程时，可运行：

```powershell
.\DeskCare-M18r1.exe --demo-scenario
```

该模式首次启动会准备虚构任务、模拟活动、提醒反馈、主动状态记录和本地日报；这些演示内容会在主界面与报告中标明，不会使用或混入真实用户数据。重复启动不会重复生成当天场景。它不连接网络、不调用 AI，也不读取真实电脑活动。

### 现场讲解顺序与预期

1. **今日**：先指出页面上的演示标识。会看到两项由内置虚构 CSV 解析并确认生成的任务，其中一项标记为“由你标记完成”；这是脚本准备好的演示状态。
2. **使用统计**：说明约 40 分钟是模拟活动估计，不是当前电脑刚刚实际采集的使用记录；统计不推断具体任务或学习效果。
3. **状态与报告**：打开本地日报，可看到一条提醒反馈（选择“10 分钟后”）、一条主动填写的状态记录，以及相应的任务和活动摘要。报告标题和正文会标明虚构演示数据。
4. **说明边界**：本场景用于讲解跨模块数据如何连起来；不会调用在线 AI、访问网络或读取真实活动，也不代表真实用户测试、健康结果或产品效果证据。

注意：`--demo-scenario` 为了稳定复现会自动跑内置 CSV 解析与任务确认服务，启动时**不会**弹出文件选择/导入预览窗口。因此不要把它描述成评委现场手动选文件的演示；若需要展示导入预览和人工确认交互，请按 `docs/M15-M18_阶段验收与Windows实机清单.md` 单独操作虚构任务文件。

## 数据位置与更新

正式模式的用户数据保存在 `%LOCALAPPDATA%\DeskCare\deskcare.sqlite3`；空白演示数据在 `%LOCALAPPDATA%\DeskCare\demo\deskcare-demo.sqlite3`；完整场景按日期单独保存在 `%LOCALAPPDATA%\DeskCare\demo\scenario-YYYY-MM-DD.sqlite3`。替换程序文件不会删除用户数据库；卸载/删除前请先从设置页导出需要保留的报告。更新程序前建议正常退出 DeskCare。

发布包目前为未签名便携程序，不是安装器；Windows SmartScreen 可能显示未知发布者提示。只有确认文件来自可信项目发布后才继续运行。
