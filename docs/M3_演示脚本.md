# M3 演示脚本

## 启动

```powershell
python -m deskcare --demo
```

演示模式只使用显式标注的 FakeActivityProvider；不会读取真实 Windows 活动。

## 规则提醒演示

1. 打开“设置与隐私”，确认首次默认“开启电脑活动统计”未勾选。
2. 勾选开启活动统计，回到“今日”，在“当前情境”中选择“普通工作”。
3. 等待演示采样建立基线；M3 不会因为单个样本直接把用户判定为需要休息。
4. 通过自动化测试或开发演示夹具将连续活跃时间推进到阈值，确认页面出现内联提醒卡片而不是弹窗。
5. 依次检查“10 分钟后”“跳过”“时机不合适”等按钮，确认卡片关闭且反馈被本地记录。
6. 选择“会议中”或“安静时段”，确认策略显示暂不提醒；选择“阅读中”也不会凭空生成强制休息结论。
7. 回到设置暂停监测，确认提醒卡片隐藏；恢复监测后重新等待有效样本。

## 边界演示

- 没有有效样本、provider 异常、空闲或长时间未采样时，不应出现“你已经疲劳”的文案。
- 截止时间临近或用户处于专注模式时，策略应延后提醒。
- 任务必须是今日页中用户已确认的任务；预览中的草稿不能影响提醒。
- 关闭应用再启动后，历史反馈只用于冷却，不自动恢复一个正在抢注意力的弹窗。

所有时间、任务和活动数字均为演示输入，不代表健康结论。
